# dsh-ar-aging

> **Repositorio oficial. El único repositorio oficial de este paquete, mantenido por PerryLink. Apache-2.0.**

</div>

Convierte un libro auxiliar de cuentas por cobrar en CSV en un informe de antigüedad: tramos de 0-30/31-60/61-90/91-180/180+ días, resumen por cliente, ratio vencido y principales clientes vencidos, con exportación CSV. Todo se ejecuta localmente, sin red ni carga de datos.

## Documentación completa

La documentación completa (instalación, permisos, ejemplos, reglas de antigüedad y solución de problemas) está en [README.md](README.md) y [README-zh.md](README-zh.md).
